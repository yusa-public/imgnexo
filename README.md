# ImgNexo – Free Browser-Based Image Utilities & Photo Tools

[ImgNexo](https://www.imgnexo.com/) is a privacy-first, 100% browser-side photo processing tool suite. Photos stay completely on your local device—zero server uploads, no registration, and no watermarks.

🔗 **Try Live Tool**: [https://www.imgnexo.com/](https://www.imgnexo.com/)

---

### 🌟 Key Features
- **Blur Image Online**: Easily blur faces, sensitive text, or backgrounds using custom brushes or boxes.
- **Unblur & Motion Fix**: Sharpen soft photos and fix motion blur in seconds.
- **Social Media Presets**: One-click crop & export for Instagram, Facebook, and Twitter ratios.
- **100% Private**: Powered by client-side HTML5 Canvas. Your images never leave your browser.
